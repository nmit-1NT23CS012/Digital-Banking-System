# Project setup

The application source and local development instructions are in place. Start with the [README](./README.md) for requirements, database setup, environment variables, API routes, and validation commands.

The database schema is intentionally empty: create test accounts through the application. This is an educational demo only; do not use real credentials, financial transactions, or personal data.

Before sharing changes, confirm that local `.env` files, generated logs, database exports, and build output are not included in the Git changes.
